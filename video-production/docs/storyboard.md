# Storyboard — More than a click

The exact shot list, timing, labels, and source takes are editable in `src/compositions/timeline.json`.

| Time | Story beat | Authentic screen and motion |
| --- | --- | --- |
| 0–8 | What if emails could do more? | Actual static HTML preview; editorial hook text changes into “DO more” with eased entrance. |
| 8–18 | Meet InboxFlow | Real dashboard and template selection in a floating browser frame. |
| 18–30 | Connect | Sandbox Shopify/Klaviyo setup, real catalog sync, variants, then an original four-node workflow diagram. |
| 30–48 | Create | Template selection, real library drag/drop, color/type changes, carousel and subscription blocks. HTML preview follows the completed sandbox export. |
| 48–66 | Experience | Simulated HTML email, a client-capability/fallback diagram, then actual hosted product options, quantity and cart actions. |
| 66–82 | Take action | Reviewed cart, confirmed sandbox checkout, and a reviewed/confirmed seven-day subscription delay. |
| 82–92 | Listen | Actual stars, review submission, branching quiz and saved preference states. |
| 92–106 | Understand | Real synthetic analytics plus a focused question in the local rule-based assistant. |
| 106–112 | Invitation | InboxFlow mark, “Make every email a moment,” actual cart success, and local demo CTA. |

The vertical cut reorders this into a 30-second mobile story: hook 0–4, editor 4–8, shopping 8–12, delivery 12–16, review/quiz 16–20, analytics/assistant 20–25, CTA 25–30. Separate timed narration and large captions are used. The 12-second hero loops between actual editor, analytics and cart-success imagery with periodic motion and no sound.
