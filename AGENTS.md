# InboxFlow engineering instructions

Use pnpm and strict TypeScript. Keep business rules in packages and API modules. Every tenant lookup must include organization identity. Do not send live emails, charge real payments, or mutate external live subscriptions. Sandbox providers persist to PostgreSQL and must be labeled. Never weaken authentication to repair tests. Validate editor documents before rendering. Changes to recipient tokens, tenancy, commerce, or consent require meaningful regression tests. Run lint, typecheck, unit/API tests, browser tests, and build before handoff; record actual failures and environmental limitations in docs/TEST_RESULTS.md. Do not claim production certification, exact reference parity, or real-client verification. No external deployment is authorized.
