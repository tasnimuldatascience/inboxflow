# Feature inventory

`Local` means persistent behavior is implemented and exercised locally. `Adapter` means provider-contract code exists; it is not a credentialed integration acceptance result. `Reduced` means a deliberate subset with its limit shown in the interface or compatibility report.

| Area            | Features                                                                                                                                                                          | Implementation                                                                                     |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Marketing       | Home, product/features, integration directory, examples/filtering, original pricing/calculator, fictional cases, contact, privacy/terms                                           | Local; contact saves locally; legal text is a placeholder                                          |
| Identity        | Registration, login/logout, recovery/reset, profile, organizations, switcher, invitations, roles                                                                                  | Local; recovery and invitations return copyable links, no mail transport                           |
| Workspace       | Overview, templates, forms, products, feeds, campaigns, flows, blocks, integrations, analytics, A/B tests, reports, assistants, team, billing, settings                           | Local routes and persistent services                                                               |
| Editor          | AST, library click/drag, reorder, inline text, content/styles, subject/preheader, mobile view, visibility, duplicate/delete, saved blocks, autosave, undo/redo, versions, publish | Local; original templates; advanced table/column layouts are reduced                               |
| Content blocks  | Heading, paragraph, image/upload, button, divider, spacer, columns, hero, footer                                                                                                  | Local rendering; columns use pipe-separated cell text                                              |
| Commerce blocks | Product, grid, carousel, cart, subscription, reactivation, swap, generic action                                                                                                   | Local workflows; richer carousel/email cart behavior is reduced                                    |
| Capture blocks  | Form, quiz, review, SMS                                                                                                                                                           | Local; branching and multi-select use hosted fallback                                              |
| Engagement      | Image carousel, flip, reveal, spin, animation                                                                                                                                     | Reduced; AMP reveal/carousel and hosted deterministic rewards; animation has static email fallback |
| Email           | HTML, AMP, text, MIME, size warnings, official AMP validator                                                                                                                      | Local; HTML validation is a safety lint, not a full client/layout validator                        |
| Catalog         | Products, variants, inventory, plans, collections, feeds, stock filters/exclusions                                                                                                | Local and Shopify read adapter; no ML recommendation claims                                        |
| Cart            | Multiple items, variants, selling plans, quantities, subtotal, discounts, persistence, expiry, checkout                                                                           | Local; no real card or purchase collected                                                          |
| Subscription    | Upcoming order, skip, delay, quantity, swap, plan, one-time addition, reactivation, immediate shipment                                                                            | Complete persistent sandbox service; live capabilities not enabled                                 |
| Forms           | Six question types, required fields, prior-question conditions, outcomes, property mappings, responses                                                                            | Local; custom result text, not arbitrary page scripting                                            |
| Reviews         | Product/rating/title/body, confirmation, duplicate prevention, provider receipt                                                                                                   | Local mock provider; commercial review providers not connected                                     |
| SMS             | E.164 validation, explicit wording/evidence, pending double opt-in, duplicate prevention, callback simulator                                                                      | Local; no SMS transport                                                                            |
| Workflows       | Ten reference journey categories, draft records, template/trigger/eligibility configuration, simulation, execution logs                                                           | Local; no scheduler or live ESP delivery                                                           |
| Analytics       | Events, confirmed revenue, engagement denominator, time series, message summaries, block aggregation, CSV, reports                                                                | Local; limited to most recent 10,000 events                                                        |
| Experiments     | Stable assignment, exposure/conversion, samples, Wilson 95% intervals                                                                                                             | Local; metrics recorded manually via authenticated API; no causal lift claim                       |
| Assistants      | Typed Refine operations and read-only analytics answers                                                                                                                           | Local deterministic fallback; no LLM configured                                                    |
| Billing         | Plans, usage, published-template quotas, downgrade checks, Stripe test checkout/signature callbacks                                                                               | Local and test adapter; no real charging                                                           |
| Operations      | Compose, CI, non-root image, SQL migration/seed, outbox/BullMQ worker, health, S3 upload, retention, audit                                                                        | Implemented; actual runtime results in TEST_RESULTS                                                |

Every block has a validated persistent schema and a static fallback. A common block schema does not imply identical interactive support in every email client.
